最新普攻动作与特效修正见 [源配置对照记录](research/COMBAT_PRESENTATION_2026-09-28.md)：50 张表改为 30 Hz、共 1,828 帧，保留原普攻变体和死亡武器挂点；按源配置前摇、收招、发射点、飞行速度与抵达时点结算，接入原法球、箭矢及三种命中特效。普通攻击期间不会被日常移动截断，头像改为独立首帧资源。职业主动技能及每件装备动态外观继续保留在未实现项中。

当前验证见 `validation/combat_check_final.log`：22 项 Python 测试、626 项 Godot 断言与完整项目门禁通过。二十分钟模拟完成 139 次击杀、7 次复活，末五分钟仍有战斗产出。原生前后朝向连续录像在 `validation/combat_motion/动作特效校正.mp4`；三种窗口尺寸、死亡、建筑头像及战斗回归通过，血条遮挡测试仍通过（162 个覆盖采样点中 160 个正确显示前排身体）。本轮新的独立视觉复核结论为 **ship**，范围覆盖现有普攻动作、原版特效、默认武器和死亡表现。
