## 原资源与明确替代

导入入口为 `tools/import_hero_detail_reference.py`。当前 `hero_detail` 资源绑定和 `art_source/hero_detail/provenance.json` 均有346项，其中296张技能图覆盖现有英雄天赋阶段中使用的四技能；逐图登记源路径、UUID、SHA-256，PNG保留同名出处sidecar。可核查源结构为 `HeroPartPnl`，技能图片由源 `skill_base`、`skill_passive`、`skill_buff` 对应 `pic` 映射。

战力字体是原Cocos BitmapFont转换的 `assets/runtime/hero_detail/power.fnt`，保留源字形矩形、烘焙颜色及 `spacingX=-5`。正文与普通标签继续使用既有 `operations/font.ttf`。角色沿用 `hero_roster` 的74套原Spine完整 `idl` 循环，按30 Hz离线烘焙；各循环以全部帧联合边界统一裁切、缩放和脚底位置，不逐帧抖动构图。列表与详情共用表现播放器，可见格才延迟加载图集，重复快照不重启动作。这是源Spine动画的离线图集播放，不是Live2D；使用默认职业武器，不新增同名替代角色或逐装备动态换装。

两处差异必须保留：

- 当前源APK未找到参考新版「装备设置」铠甲圆图，使用原包同色圆盾 `tmp/pvp/pvp_anniu_fangshou.png`，UUID `fed39c10-cc2e-4907-a5fd-cb2995ae6cfc`。该按钮可打开真实装备管理，但图像尚非该处像素1:1。
- 「更换英雄」胶囊按参考几何以Godot样式绘制，按钮关闭 `flat` 以呈现椭圆底；它是本轮绘制形状，不能标作原切图。

其余源背景、属性图、状态图、技能图、星级与分页纹理按来源登记使用；本记录不把这些已核查材料扩大成整页每个像素或全部子页已经还原。

## 状态、钱包与本地规则

`TownHeroManagement.roster()` 为有地图实体的英雄提供私有钱包和独立复制的 `needs` 快照；尚未进入地图的储备英雄返回空 `needs`，四项状态显示「—」，浮层明确说明进入地图后开始记录。空快照不是四项100%，也不是生命或需求为零。

`hero_donate` 只接受正整数且不超过公共金币的数量；成功后从公共余额扣除并记入对应权威英雄钱包。地图英雄写入实际地图对象，未入地图英雄写入其拥有记录；无效输入、非正数或余额不足不更改两边余额。

| 规则 | 当前实现及来源界限 |
| --- | --- |
| 魔气增加 | 地图英雄击败怪物增加1魔气，依据源 `c89_jhzl` 的对应关系。 |
| 城内净化 | 城内逻辑步以公共净化之力与魔气1:1抵扣，数量不超过现有两者，公共净化为零不清空魔气。浮层当前魔气参考容量为1100。 |
| 饥饿/疲劳/心情 | 沿用既有Demo归一化0–100范围，不能把当前百分比当作原服务器原始属性值。 |
| 普攻事件 | 当前地图攻击开始检查饥饿和疲劳均大于零，并扣0.32饥饿。该挂接点不证明全部职业主动技能消耗已同步。 |
| 受伤事件 | 当前地图受击扣0.2心情；心情归零时地图攻击使用0.9倍率。 |
| 野外持续消耗 | 保留旧模拟每秒饥饿0.32、疲劳0.26、心情0.2的持续消耗，与本轮事件扣除同时存在。 |

新事件挂接由 `town_hero_needs.gd`、`town_attack_sequence.gd`、`town_combat.gd` 和 `town_hero_simulation.gd` 实现。城内即时批量净化、0–100归一化、持续消耗与事件扣除并存均是当前本地数值/时机边界，不能据此宣称原客户端及服务端全部需求算法一致。UI只读这些实际变化，不靠浮层、动画结束或参考截图决定规则。

## 入口与返回

- 卡片或阵容行进入独立全屏页；旧 `main_dialogs` 的通用hero详情分支已删除，不保留双入口样式。
- 进入时保存英雄序列；前后切换首尾有界，「更换英雄」使用同一序列，不擅自包含无法从该入口访问的英雄。
- 关闭详情回到原英雄抽屉或原阵容上下文；抽屉的排序和滚动位置继续保留。全屏详情与其子弹窗阻断下方地图输入。
- 升级、队伍切换、锁定/解锁及待命英雄遣散放在属性信息入口；装备选择继续提交 `hero_equip`；已穿装备进入独立详情，回购提交 `hero_equipment_buyback`，旧免费卸下入口及 `hero_unequip` 命令已删除。神器槽进入神器管理。
- 宠物/神器的仓库、图鉴、升级、装备/卸下、锁定、重置、分解和宠物升星继续沿用已有状态接口；背包只展示当前英雄的私有 `bag`，点击物品查看实际数量与说明，不提供公共库存使用操作；公共装备仓库仍由装备选择入口读取。
- 装备图采用既有 `operations.quality_N` 质量底框承托真实透明图。穿脱回归发现源通用装备职业0以浮点载入时，严格类型数组成员检查会误过滤/拒绝；管理命令及两个列表入口已统一转为整数后比较，通用装备按实际职业规则呈现与穿戴；本轮普通装备移除由付钻石回购承担，不改源表含义。
- 状态浮层再次点本图标关闭，点另一图标切换；外部点击、英雄切换、分页切换和关闭页面都会清除旧浮层。
