# 招募界面与本地结算（2026-09-30）

## 范围与依据

按用户本轮九张截图实现招募抽屉、说明、心愿选择、卷轴购买、刷新、三门台招募动画、成功结算、剩余候选和换批确认。保留已授权的本地前端 demo，地图不增加活动图标。截图顶部白色小游戏容器不属于游戏画面。

源查询从 本机来源索引（未随包提供；[资源来源登记](../../THIRD_PARTY.md)） 开始。核对过的源模块包括 `RecruitHomePnlCtrl`、`RecruitModel`、`RecruitRefreshPnlCtrl`、`RecruitSuccessPnlCtrl`、`RecruitInterludeAnimPnlCtrl`、`CptZhaomu0a` 和 `CfgHelper`；配置依据为 `c29_zm_pond_pro`、`c29_zm_pond`、`c29_zm_jg2`、`c29_zm_jg3`、`c25_public`。源代码描述客户端展示和请求契约，不含服务端抽取实现。

界面使用源招募室、船长、进度框、按钮、门台、光束、职业/元素图标和成功横幅。人物沿用已有原 Spine 待机采样；成功横幅从源 `js_welcome_XH` 骨骼采样为16帧，保留原骨骼、纹理和哈希。新版心愿入口、龙魂页签与确认框勾选底图在旧 APK 中不匹配，直接使用用户截图的 AtlasTexture 区域；原截图完整保留，未重绘或生成冒充源图。

资源清单、原图哈希与采样参数见 `art_source/recruitment/provenance.json` 和相邻 `.png.json`；导入工具为 `tools/import_recruitment_reference.py`，横幅烘焙工具为 `tools/bake_recruitment_ribbon.cjs`。

## 实际操作链

1. 底栏招募打开地图上方的固定高度抽屉；船长、等级进度、卷轴数、倒计时和三位待机英雄显示当前状态。概率随尚未招募的候选重算。
2. 首次招募消耗一张英雄招募卷轴；没有卷轴则进入购买界面。购买支持减、加、重置、+10、+100，每张100钻石，确认时重新验证余额并原子扣费。
3. 招募指令先确定结果、扣费、发放英雄或碎片和经验，再把不可变回执交给动画。门台灯光播放约5.2秒；点击空白跳过到成功页，不再次抽取或扣费。
4. 成功页读取已结算回执：新英雄进入拥有名单；已拥有英雄显示对应星级、碎片进度和本次增加量。关掉结果后，已招募者显示勾选，剩余者继续参与抽取。
5. 第二次、第三次按源价格表消费钻石。已招过至少一人后可换一批：取消保留原池，确定后免费换三位；「今日不再提醒」仅对本游戏日生效。三人全部招完自动换批。
6. 未抽取时可打开刷新界面：每日三次免费刷新由本地直接完成，钻石刷新消耗50；本次停船最多手动刷新10次。倒计时归零自动换批并重置停船刷新次数。「免广告特权／每日送×10」横幅可点击查看权益；该推广不属于已排除的地图活动图标。关闭弹窗/抽屉恢复原页面。
7. 心愿卡未获得时可查看图鉴详情；获得后可选中/取消。招募等级徽章进入共享图鉴。龙魂技能保留截图页签及可查看锁态，本轮没有实现其完整子系统。

## 规则与版本边界

| 项目 | 本轮实现与依据 |
|---|---|
| 候选入池 | 导入155条源池条目，按等级品质、子池和条目权重选三位不同英雄；普通零权重条目不进入随机池。抽取使用既有命名 RNG 流。 |
| 三人中抽取 | 使用 `color2_pro` 至 `color5_pro`，不使用候选生成的品质权重，也不平均分配。3级艾登/索非亚/安德鲁的条件概率为30.69%/13.86%/55.45%；安德鲁抽走后为68.89%/31.11%。 |
| 价格 | 首次卷轴1；第二次根据剩余最高品质及该品质人数读取 `c29_zm_jg2`；第三次读取 `c29_zm_jg3`。累计招募大于3时，每游戏日第二、第三次各有一次七折，浮点向下取整与源客户端一致：180变125。 |
| 奖励 | 重复英雄按源定义转20碎片，每次招募加5经验，超过当前等级门槛升级并保留溢出经验。 |
| 停船/刷新 | 公共配置1175为1800秒；1177/1178/1179/1180分别为每停船10次、每日免费3次、免费间隔1秒、付费50钻。新版参考的47分钟不作为旧包配置事实。 |
| 心愿 | 旧包没有截图所示同版心愿系统。demo 以锤锤为心愿对象，拥有后启用；其旧池零权重条目启用100基础权重，再乘2，仍保留等级品质和子池门槛。此规则不是已核实的原服规则。 |
| 动画 | 复用源人物、门台、灯光、横幅及金/紫光柱各15张源序列图，本地5.2秒表现时序；未逐帧证明与源 Cocos 动画曲线完全一致。 |
| 广告和支付 | 免费刷新直接本地结算；卷轴购买仅扣游戏钻石，无广告 SDK、现金支付或服务器请求。免广告特权推广可查看截图所示权益；旧包 `FreeAdsPnlCtrl` / `c70_mianguanggao` 有3日、1月、永久卡，未核实新版每日卷轴权益对应商品，因此此入口不模拟激活/发奖，也不伪造商品价格。 |
| 运行状态 | 沿用当前项目的进程内状态。游戏日推进负责重置每日计数；未新增跨进程保存或真实日期同步。初始不额外赠送卷轴。 |

## 实现边界
