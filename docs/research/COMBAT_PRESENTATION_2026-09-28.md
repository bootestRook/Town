# 普攻动作与特效校正

用户反馈人物动作和特效与源项目不符。本轮修正当前三名英雄、疾风狼和棕熊的基础表现，不将尚未实现的主动技能称为已还原。

## 核实的差异与处理

| 原实现差异 | 本次处理 |
| --- | --- |
| 只选一个 `atk`，没有读取实际普通攻击配置 | 按 `skill_base` 选择战士/法师各三种、弓手两种、怪物一种动作；前后朝向均保留。表现使用独立随机流，按源 `Math.round` 的权重选择，不消耗掉落随机流。 |
| 每个动作固定 12 帧，长待机动作仅约 4.5 帧/秒 | 原骨骼离线按 30 Hz 采样，共 50 张表、1,828 帧；渲染补上领域固定步长剩余时间。头像另取完整首帧，避免把多行序列当成单行。 |
| 攻击开始立即扣血，0.6/0.65 秒切回待机，移动还能打断攻击 | 使用源配置的出手与结束时间；普通移动、回城和召唤在收招后继续，死亡取消尚未发射的攻击。 |
| 金色线段代替全部攻击特效 | 使用原金色法球、箭矢和三种白色命中序列，命中特效按 50 ms/帧播放。远程弹体以 1,000 世界单位/秒追踪命中点，到达后才扣血。 |
| 骨骼内置展示武器及始终隐藏死亡武器槽 | 使用源默认黑铁剑、基础弓、基础法杖图；根据原骨骼 `die` 事件切换手持与掉落挂点。 |

| 角色 | 普攻配置 | 骨骼动作 | 出手时点 | 收招时间 | 弹体 / 命中特效 |
| --- | --- | --- | --- | --- | --- |
| 艾比 | 1002 | atk1、atk2、atk3 | 0.500 秒 | 1.160 秒 | 1104 / 50021 |
| 特伦斯 | 1000 | atk1、atk2、atk3 | 0.500 秒 | 1.000 秒 | 无弹体 / 50006 |
| 芭芭拉 | 1001 | atk1、atk2 | 0.600 秒 | 1.000 秒 | 1105 / 50016 |
| 疾风狼 | 10000 | atk | 0.277 秒 | 0.833 秒 | 无弹体 / 50021 |
| 棕熊 | 10001 | atk | 0.333 秒 | 0.833 秒 | 无弹体 / 50021 |

上表为攻速倍率 1 的时间。普攻结束后的 0.1 秒间隔与配置冷却同时约束下一次出手。领域仍按 0.05 秒固定步进，判定会落在首个越过配置时点的逻辑步；动画不会反过来决定伤害。特效尺寸、角色发射点及受击点取原表，坐标换为 Godot Y 向下并随朝向翻转。

## 证据与复现

源目录 `F:/GameResearch/佣兵小镇` 只读访问，仅提取资源和核查行为，不移植业务源码。

- `04_配置表/JSON原表/resources/common/json/skill_base.json`：普通攻击动画名、出手/结束时间、弹体、命中特效与飞行速度。
- 同目录 `c52_skill_bullets.json`、`c52_skill_effect.json`：原图、缩放、序列间隔及挂点；`c25_zww.json`、`c59_guaiwu_model.json`：发射/受击坐标；`c39_zhuangbei.json`：默认武器。
- `02_代码模块/btActiveSkill.js`、`btRoleAttack.js`、`btBullet.js`：计时触发、收招间隔与弹体抵达后结算。
- `btCptHeroCharacter.js`、`HeroZwwUtils.js`：动作变体选择、默认武器贴图替换与死亡挂点事件；`btCptEffectSeqFrame.js`：命中特效的帧间隔。
- 本项目 `art_source/heroes/combat_sources.json`、`bake_jobs.json`、`provenance.json`：提取的配置、资源来源和哈希。

重新生成：`python tools/import_hero_reference.py` → `node tools/bake_hero_spine.cjs` → `python tools/register_hero_assets.py` → `python tools/project.py data` → Godot 导入 → `python tools/project.py assets`。运行时不依赖原包目录或 Spine 库。

验证入口：`tests/test_town_attacks.gd` 检查前摇、飞行、命中一次、死亡取消和怪物时点；`tools/tests/test_actor_art.py` 检查帧格与透明边缘；`tests/capture_combat_motion.gd` 保存原生前后朝向出手序列与三种窗口尺寸。截图和录像在 `validation/combat_motion/`，完整门禁记录见 `validation/combat_check_final.log`。

最终完整门禁通过 22 项 Python 测试、626 项 Godot 断言及启动冒烟，无脚本错误。原生录像为 750×1334、30 fps、96 帧；角色回归与血条遮挡回归零失败。独立全范围视觉复核结论为 **ship**，核查了前后出手、死亡、建筑头像、实际战斗及三种窗口尺寸；该结论仅适用于本文范围。

后续已废弃 30/85 圆形间距，改为原地图与野外站位规则；坐标、血条和导航的最新实现及门禁见 [人物与导航校正](ACTOR_NAVIGATION_2026-09-28.md)。上方 626 项断言与复核结果为该次动作特效阶段的历史记录。

## 保留边界

当前只实现普通攻击。主动职业技能、完整技能特效/音效、每件装备动态外观与完整骨骼运行时仍在后续清单；当前使用原默认武器外观，装备属性交易继续有效。基础伤害、生命、需求衰减和寻路节奏仍是 Demo 规则，不宣称完整复刻原版战斗数值。
