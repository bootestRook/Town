## 行为与状态转换

| 状态 | 行为 | 离开条件 |
| --- | --- | --- |
| 城内待命 `standby_idle` | 待机，不消耗需求或生成收益 | 停留时间结束，选择城内可达目标 |
| 城内闲逛 `standby_walk` | 沿既有菱形格道路移动 | 到达后待机或继续巡游 |
| 返城待命 `standby_return` | 野外撤下后沿原路网返城 | 到达城内目标后进入待命 |

- 通过既有 `hero_team` Command 切换，不由 UI 直接改英雄状态。加入队伍后恢复原战斗、掉落、回城消费及复活循环；取消出战即时停止新攻击、怪物锁定、关联弹体与建筑召唤，并保留当前位置、生命、需求、钱包、装备和背包。
- 未出战不主动战斗、不获得掉落、不新发起生活消费或装备交易、不持续扣饱食/精力/心情；不因撤下自动恢复生命。已经付费的服务与死亡/复活过程正常完成，然后转入待命；不重复付费、不退款、不瞬移返城。
- 待命使用同一导航与动画系统。停留目标按原 60×80 命中矩形预留间距，避开其他英雄现有或预约位置；途中交会保留源城内穿行规则，不增加物理推挤。修正对角线恰好经过菱形格公共边角时被瞬间误判为地图外的问题，没有改变寻路对角线模式或建筑占地。
- 点击城内待命英雄仍可放大选中；按2026-09-30用户后续要求，城内巡游和野外返城中被选中均继续正常行动并持续跟随。详情按钮打开对应英雄的信息页，取消选中不改变原行为。

## UI

- 出战：绿色名字，原尺寸血条和等级标；未出战：蓝色名字，隐藏血条及等级标。颜色表达出战状态，不表达品质；身体、姓名、阴影及整个人物的 Y 排序保持原逻辑。
- 英雄列表显示出战/待命/返城待命；已有详情页显示出战状态与当前行为，原队伍按钮使用“出战 / 取消出战”。
- 交易所及装备店沿用现有英雄条目，待命英雄的召唤按钮禁用并显示“未出战”。地图没有新增说明栏、状态面板、入口或按钮。
