# ADR 0005：三名英雄的自主经营与野外循环

状态：采用。用户批准阶段评估，指定艾比（法师）、特伦斯（战士）、芭芭拉（弓手）。

TownOperations 继续拥有全部小镇可变状态。行为决策、寻路、移动、战斗、服务调度各自拆成小型领域模块；不增加 Autoload、EventBus、跨 Feature 依赖或行为树编辑器。用任务状态与明确的完成/取消规则实现本阶段行为，不移植原包业务源码。

定义仍走 CSV/schema 管线：三名英雄、两种怪物、掉落关系、可行走格与动画绑定。原地图预制体排除格转换为世界坐标导航格，建筑占地独立阻挡。寻路使用目标引擎内置 AStarGrid2D。原骨骼按 c25_zww 和 spine 配置选择身体、头发、面部，离线烘焙；运行不依赖 Spine。

组合根注入现有 RngSet，战利品使用具名 town.loot 流；不修改 RNG 契约。战斗结果由领域固定步进结算，动画仅响应事实。装备属性分别进入生命、攻击、防御，删除旧的计时冒险与全材料赠送逻辑。

恢复中的服务不可重复收费或因普通召唤被取消；召唤排在完成服务/复活之后。满员按先到先服务，座位只在到达且付款条件满足时占用，退出立即释放。缺货/缺钱等待有明确原因并定期重评；没有玩家生产或收购时允许等待，不自动造货、赠款或恢复。

先开放一片野外、疾风狼与棕熊，采用原掉落物品和概率；战斗基础数值、需求衰减与节奏标为 Demo 调参。复活祭坛开放基础自动排队与倒计时，沿用一级 3 席、15 秒、10% 生命，后续进入医院。完整技能、经济成长、复活加速/升级、其他区域和存档仍在清单中。

固定界面保留 .tscn；地图不增加说明栏、调试文字、导航或测试按钮。验证使用领域测试、原生输入截图与二十分钟模拟日志。

用户追加明确要求的角色标识：英雄绿色名称、脚底绿血条、等级圆标；怪物金黄色名称与红血条。固定结构为 actor.tscn，仅身体贴图镜像。动画定义记录可见顶端与脚底，避免透明留白让血条脱离角色。原包角色默认朝左，向右行走/攻击时镜像；上行使用背面。英雄等级为显式定义字段，本轮显示 1 级，不加入经验与升级系统。

2026-09-28 裁切与血条修正：动画定义增加帧格行列及帧宽高，各动作依据完整姿态边界扩展画布，保持统一脚底锚点与身体缩放；删除固定 256×256 的假设，不添加旧格式兼容。血条采用源项目 TextureProgressBar 贴图与 58×9 / 54×5 尺寸，等级标 19×19；生命颜色和死亡隐藏跟随源规则。角色子节点不单独提升 Z，整个角色按脚底 Y 与世界对象排序，防止后排血条盖住前排身体。

动作与特效校正：在现有 CSV/schema 中增加普攻时间线与特效定义，来源为 skill_base、c52_skill_bullets、c52_skill_effect 及角色挂点。动作按源骨骼 30 Hz 采样并保留普通攻击变体；表现使用独立随机流选择变体，不影响命中和掉落。TownCombat 拆出普攻执行器：前摇、发射、飞行、命中和收招由领域计时驱动，表现只读取结果；攻击完成前不被普通移动/需求决策截断，死亡取消未发出的攻击。移除即时扣血与临时画线，使用原图箭矢、法球与命中特效。此修正只覆盖当前普通攻击，不扩展主动职业技能。
