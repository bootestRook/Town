# ADR 0004：八类建筑的本地经营闭环

状态：采用。日期：2026-09-28。

用户要求可点击的二级页面及真实的材料、生产、英雄消费链，并确认选项 1、2、3 全部实施。本轮实装交易所、医院、餐馆、旅馆、酒馆、武器店、防具店、饰品店；其余建筑记录资源和操作链。

沿用 town Feature 与 CSV/schema 管线，新增物品、四类生活服务与等级、七种装备配方、英雄初始配置。TownOperations 是独立状态所有者，由组合根驱动时间，内部把移动调度和装备规则拆成两个模块；页面只发送意图、读取副本。金币分别归镇长及每位英雄所有。材料、成品、预购剩余量、床位和服务计时由领域层结算。关闭页面不暂停世界，不重置库存。

医院拖入材料时原子消耗整批可用材料、增加成品。原包约两秒的生产动画属于表现；治疗的十二秒属于规则。预购不预付，英雄到交易所时按双方库存、订单及镇长余额结算；无货、无钱或床位不足时等待，不能虚构交易。

地图仅增加可点击建筑及英雄表现，不恢复之前删除的地图说明栏、缩放按钮、区域导航。二级页面按用户截图和原包素材搭建固定 .tscn；动态物品和英雄条目实例化独立场景。

允许离线资产烘焙工具依赖 PixiJS 7 与 pixi-spine 4（含 Spine 3.8 解析器），使用既有 Playwright/Chromium 生成 PNG 序列；游戏运行时不增加依赖。依赖仅在 .godot 工具缓存安装，版本固定，来源与转换记录写入资产 provenance。工具不修改参考包，不复制商业业务代码。

为验证闭环，八类建筑初始建成，生活建筑五级、交易所一级、主城条件值五级。初始镇长金币 60000，四类材料各 8，五类锻造材料各 30；三名英雄各持 150000 金币，便于验证售价 63100 的饰品。以上为公开的演示初值，不宣称原游戏新档配置。装备须英雄到店并由玩家确认出售才转移所有权，不能自动买走。

野外产出、伤损和装备影响冒险速度采用确定性模拟，非完整战斗还原。装备使用配置中的基础属性和基础价格，未伪造服务端随机词条、星级和价格结果。详见研究核查清单。完整战斗、养成、联网及跨会话存档另列后续事项。
