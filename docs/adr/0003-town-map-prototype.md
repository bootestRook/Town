# ADR 0003：小镇地图原型与竖屏入口

日期：2026-09-28；状态：已接受（用户指定第一阶段）。

当前入口改为 750×1334 竖屏地图。只完成场景浏览、建筑初始摆放及建造前后独立外观；英雄、战斗、经营、存档留在后续清单。

采用独立 `town` Feature。领域拥有建筑当前外观状态，组合根调用 Feature 公开接口，表现层只读取快照。地图位置、资源和锚点为不可变 CSV Definition，经已有 schema 管线生成 JSON，不引入新的运行时数据格式、依赖、Autoload 或跨 Feature 依赖。

背景沿用参考项目六块 2066×2427 图的 3×2 拼接。Cocos 坐标转换为 Godot 向下的 Y 轴；透明图片保留原画布，显式抵消精灵裁切偏移。道路在地面层，建筑及杂物按落点 Y 排序。建筑保持配置表的初始位置，本阶段不提供自由迁移或建造经济。

用户已明确移除原型资源复制限制。本项目按本次授权复制提供的拆包美术及对应摆放数据，资源登记为 `third_party`，保存来源与 SHA-256；不修改外部拆包文件，不复制其业务代码。此前研究中的资源审批阻塞已被本次授权解除。

新增 `town_texture` 无损纹理策略，单文件上限 8 MiB、最大边长 4096；保留原始贴图质量。不添加游戏说明和按钮，因此不导入额外 UI 字体。源文件和运行时文件由工具复制并校验，运行不依赖拆包目录。压缩纹理、分区加载与导出体积优化留给目标平台确定后的阶段。

旧示例 Feature 保留为框架独立测试样例，默认入口只装配小镇。不保留旧主界面或旧入口回退。窗口使用 canvas_items/expand，尺寸跟随项目配置。

验收：真实 Godot 场景渲染；地图连续、拖动不改动建筑状态、滚轮锚定鼠标、缩放与边缘受限；18 栋建筑位置可查，15 栋有不同的前后资源，3 栋源配置仅有建成资源；全流程 check 通过。

用户后续纠正：移除所有自行增加的说明、状态栏、区域导航与演示按钮。建造外观切换通过领域接口测试，不提供未要求的演示面板；此限制已写入 AGENTS.md。
