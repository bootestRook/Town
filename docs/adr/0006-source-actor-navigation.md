# ADR 0006：原骨骼坐标与原地图导航格

状态：采用。用户要求继续按源项目校正动作、血条、寻路及碰撞。

废弃按 alpha 边界归一化角色身高、脚底锚点和 20×20 重采样导航格。动画仍离线烘焙，保留原骨骼坐标原点及源缩放，定义记录帧内原点；名字挂点、字号取源预制体/怪物表。血条保持源预制体相对角色根节点的位置，不能为凑齐可见脚底另行偏移。

在现有 CSV/schema 管线内增加地图区域定义与角色表现定义；导航表记录区域内原始菱形格坐标。小镇采用 38×19、第一野外采用 84×42，原预制体排除格、建筑/不可通行装饰占格及建筑门口全部从来源导入。两个区域通过源小镇出口的世界坐标连接，删除手工增宽的桥梁通行区。城内继续使用引擎 AStarGrid2D，在格坐标中求路，转换为世界坐标移动。

单位移动不再使用自加的 30/80/85 半径硬碰撞或侧跳；源城内允许英雄交会，野外选择未被战斗站位占用的目标格。普通追击按源网格逐步接近，删除远程自动风筝后撤。域内位置仍由固定步进拥有，表现用相邻状态插值平滑移动，不写回领域。

源职业移动属性存在随机区间，当前本地三英雄使用区间中值作为明确初始化值；城内/野外像素倍率均取 c25_public。无服务端实例属性，不声称与任意原版存档逐帧一致。其他经济、成长和主动技能保持既有待办范围。
