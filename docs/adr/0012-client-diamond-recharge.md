# 客户端钻石充值

用户授权以客户端模拟充值替代服务器校验，仅实现钻石页。六档金额来自 c70_shop_1；商品、卡框和首充标记来自 c70_shop 与 GiftShopPnlCtrl。每档首次额外赠送同等钻石，之后仅基础数量。

TownDiamondShop 持有不可变商品定义，main.diamond_purchases 持有本次运行各档购买次数。购买命令必须携带快照中的下一个订单号；无效、过期或重复命令不产生修改。有效命令原子增加钻石、次数与订单并返回结算回执。与现有 Demo 一样，不新增磁盘存档、支付 SDK 或网络请求。

表现只播放已结算回执，动画、关闭和跳过不得再次发奖。奖励采用源 RewardBgAnim 的 js_welcome 入场及 js_welcome_XH 循环、BuildEqNode 的 30 Hz 爆光、0.333 秒揭示物品和源 49 号音效。底栏仅钻石充值。快捷页暂时隐藏来源页面，返回恢复其分页、滚动、弹窗上下文。

删除原钻石通用列表、模拟购买确认弹窗路径。既有礼包领域规则不在本次修改范围，未加入新页入口。数据仍采用已有 CSV/schema 与资源绑定格式，不引入新的全局服务或随机契约。
