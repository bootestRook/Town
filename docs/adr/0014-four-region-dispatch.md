# ADR 0014：四区派遣与地图行走

2026-09-30，采用。用户指定还原地图派遣信息UI与操作逻辑，并明确本轮只完成四区派遣、门槛校验及真实往返移动；后两区怪物、战斗和掉落另做。

源 `FightSetPnlCtrl.js` 规定四区布局、同一区域多选、顶部全部派遣、低战力确认及关闭保存。派遣按目标区域分组而非瞬时位置。`c8_map` 第一难度的推荐战力为0/1000/2000，地下城解锁条件为0/9/18；战力为软提示，解锁为硬限制。源解锁状态来自服务器，本地Demo按现有地下城进度满足条件即解锁，不新增服务器、地图解锁入口或难度系统。

以 `assigned_area` 替换旧 `city_assigned` 二值路径，不保留旧弹窗和状态兼容层。页面只持有尚未提交的派遣草稿，领域提供预检与原子提交接口；关闭时提交，经拒绝则留在页面并显示原因。新增CSV定义沿用现有数据管线。没有新增跨Feature依赖、全局服务或Save/RNG契约。

原导航扩展为主城和三个原野外格网，使用源出口，经主城连接不同野外。原第一野外继续战斗；后两区到达后停驻，保留需求触发返城、召唤、撤下和复活路线，不假造怪物、收益或瞬移。派遣不改变地图上阵名单和独立挑战队伍；只有出战英雄可派遣，正在独立挑战或号角战斗的成员维持现有保护。

验收：截图三个约定尺寸；分组、同区多选、取消选择、顶部全部派遣、低战力确认/取消、锁区、关闭保存及再次打开；四区往返连续路径无不可达点；已付费服务、返城和队伍身份不被派遣破坏。未接入的后两区战斗单列待办。
