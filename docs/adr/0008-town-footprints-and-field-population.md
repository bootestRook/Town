# ADR 0008：建筑位置对齐与源野外怪物规则

状态：采用。用户指出怪物过多、排列整齐，以及人物穿过建筑；本次同时修正。

建筑/装饰占地仍采用原配置格。表现节点补入源 `BuildingEditorComponent.setNodePosition` 的高度偏移 `(height-1)*19/2`（Godot Y 取负），使原贴图、门口、碰撞格及 Y 排序在同一坐标系。装饰表增加高度，仍使用现有 CSV/schema 管线。城内 A* 保留八邻居，但斜向移动要求两侧均可通行，避免切建筑角；中途改目标先回到当前可行走格中心，再沿完整格路前进。这项防切角约束比源代码严格，不扩大障碍占地、不引入英雄互推。

删除根据拥有英雄人数计算怪物数量和矩形网格出生的路径。第一野外当前使用源 `c6_map_1` id=1：3 狼＋3 熊、7 个候选出生点、10 秒补充。增加 `town_monster_spawns` 定义表及怪物的 `spawn_count`、`patrol_range` 字段；导入器从地图 prefab 与原表生成，运行时无源目录依赖。不新增可切换关卡界面或未请求的首领内容。

`TownMonsterPopulation` 在 town Feature 内负责出生点选择、重生及范围巡逻；伤害与攻击仍由既有 Combat 执行。使用注入的命名随机流 `town.field`，与掉落及城镇巡游隔离，不改变 RngSet/Save 契约。出生点占用按当前活体实例计算，巡逻偏移按成对数据正确选择；不照搬源包中可疑的占用计数与索引错误。停留 2.5–5 秒、范围 300、索敌/战斗转换均由领域驱动。

验收覆盖完整建筑占地、连续移动与途中换路、正背面遮挡、各建筑门口可达、野外普通怪上限、随机重选点、停留/巡逻/接敌、反复死亡补充及既有经营循环；保留待命名单、身体比例、名称和血条规则。
