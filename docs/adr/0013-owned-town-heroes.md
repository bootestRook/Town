# ADR 0013：初始拥有名单与招募入城

状态：采用，2026-09-30。

用户要求初始只拥有艾比、特伦斯、芭芭拉三个绿色佣兵并默认出战，其余需要招募。角色资源目录不等于拥有名单。`town_heroes` 新增 `initially_owned`，仅这三名为真；原有48人的初始化展示路径移除。保留既有74名招募定义，并补齐其中尚未烘焙的26名地图动作，防止招募成功却无法入城、上阵。

Town Feature 内的 `TownHeroPopulation` 持有地图定义、实例创建与名册同步；招募仍由 `TownRecruitment` 原子结算，公开 `TownOperations.main_command` 随后同步地图实例。新招募者默认待命，不占地图或独立挑战队伍名额；重复招募只结算灵魂石，不复制角色。原有招募支付、概率、等级、动画及出战容量不改变。

待命起步立即选合法城内目标，取消统一开局等待；到达目标后保留原40%概率停3秒。命令同步不重复初始化已有角色、路径和计时。画面只为实际出现的角色加载动作，避免开局加载整套未拥有角色的动作纹理。初始英雄不可遣散，后招募者沿用遣散能力：须先撤下、非独立战斗/付费服务/死亡恢复状态；移除名册时同步释放地图对象与引用。

新增表字段沿用现有 CSV/schema 管线，无 Save、RNG 契约或跨 Feature 依赖变更。验证包括初始3人、待命首个逻辑步、招募/重复招募/上阵/撤下/遣散、全招募池动作覆盖、拥挤路径与既有经营循环；压力测试使用显式全员拥有的测试数据，不修改产品初始状态。
