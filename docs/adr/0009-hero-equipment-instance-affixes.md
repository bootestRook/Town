# ADR 0009：英雄装备实例词条

日期：2026-09-29。状态：接受。

英雄背包、装备详情和待机动画按新参考还原。当前七个制作配方遗漏了源初始词条，详情不能用截图固定数值补齐。沿用已有 CSV/schema 管线，从 c39_zhuangbei、c39_citiao 和回购表导入七件装备的静态规则；实例保存独立词条值。打造通过注入的命名随机流 town.equipment 在配置闭区间均匀抽样，这是明确的本地 Demo 规则，不宣称与未知服务器分布相同。该流与掉落、招募、远征分离。

装备规则属于 town Feature，由 TownOperations 组合、TownWorkshop 负责打造实例、TownHeroManagement 负责回购。回购校验当前英雄、部位、实例序号、战斗状态、库容量和钻石，再一次性完成扣款和转移。旧免费卸下入口与命令删除，不增加兼容路径。当前七件品质2均低于源洗练门槛5，洗练入口只返回品阶限制且不扣费；本次不新增尚无可取得装备的高阶洗练系统。

词条映射到现有攻击、闪避、移动速度和归一化饥饿消耗。私有背包只读快照，物品说明不提供公共库存操作。分享使用本机剪贴板，不接入外部聊天。动画沿用现有离线 Spine 烘焙依赖，将单帧替换为完整待机图集；不新增运行依赖、存档格式、Autoload 或跨 Feature 契约。

验证：确定性词条和范围、私有库存隔离、回购原子性与重复请求、品阶拒绝、属性实际变化、原动作多帧与三尺寸点击验收。
